# Beverage Container Return Scheme / Return Right (BCRS Ltd)

National, government-established deposit-return scheme for PET bottles and aluminium cans, officially launched 1 April 2026 with over 1,070 reverse vending machines ('Return Right') deployed island-wide; consumers pay a 10-cent deposit per container, refunded on return.
